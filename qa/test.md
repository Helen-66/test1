# QA Workflow Rules

This document defines the constraints and process guide for QA work in this repository.

## Hard Rules

1. **QA work must only occur within the `qa/` directory.** All modifications and new files related to QA must be placed inside `qa/`.

2. **Development source code must not be modified.** QA processes must never alter source code outside of the `qa/` directory.

3. **Bugs and issues must be recorded in `qa/bugs/`.** Any bugs or issues discovered during testing must be documented as files within the `qa/bugs/` directory.
